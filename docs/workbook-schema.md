# 工作簿结构约定

`scripts/merge_workbook.py` 假定工作簿至少有 `背景`、`达人`、`点位`、`单品` 四个 sheet。

## 背景

| 列 | 含义 |
|---|---|
| A | 达播 ID |
| B | 当前机构 |
| C | 旧机构 |
| D | 达播昵称 |

机构映射优先级：CLI `--org-override` → 背景 B → 原表达人 A → `未知`。

## 达人

A 机构、B 日期、C 达人 ID、D 达人名称、E–W 19 个指标。
键：`(日期, 达人ID)`。

## 点位

A 达人 ID、B 达人名称、C 机构、D 日期、E 内容 ID、F 内容名称、G–AA 21 个指标。
键：`(日期, 内容ID)`。

## 单品

A 达人 ID、B 达人名称、C 机构、D 品线、E 日期、F SKU ID、G 商品名称、H–W 16 个指标。
键：`(日期, 达人ID, SKU)`。

## 写表行为

- 只保留有日期的行，丢弃 `#N/A`/空占位行。
- `--replace-dates auto` 时删除 raw 中出现日期的旧行，再写入新行。
- 其余日期原样保留。
- 同键保留非空字段更多的一条。
- 按日期升序重写，冻结表头 `A2`。
