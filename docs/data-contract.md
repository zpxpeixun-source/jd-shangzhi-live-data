# 数据契约

`extract` 输出：

```json
{
  "days": [
    {
      "date": "YYYY-MM-DD",
      "creators": [
        {"author": "达人ID", "authorName": "达人名称", "metrics": []}
      ],
      "contents": [
        {"author": "达人ID", "authorName": "达人名称", "contentId": "内容ID",
         "contentName": "内容名称", "publishTime": "YYYY-MM-DD HH:mm:ss", "metrics": []}
      ],
      "products": [
        {"author": "达人ID", "authorName": "达人名称", "skuId": "SKU",
         "skuName": "商品名称", "metrics": []}
      ]
    }
  ],
  "errors": []
}
```

## 指标顺序

### creators（19）

1. 内容浏览量
2. 内容访客数
3. 人均停留时长
4. 引导进商详访客数
5. 引导进商详浏览量
6. 引导加购人数
7. 引导加购次数
8. 当日引导成交金额
9. 当日引导成交人数
10. 当日引导成交单量
11. 当日引导商品成交件数
12. 7日引导成交金额
13. 7日引导成交人数
14. 7日引导成交单量
15. 7日引导商品成交件数
16. 15日引导成交金额
17. 15日引导成交人数
18. 15日引导成交单量
19. 15日引导商品成交件数

### contents（21）

内容浏览 3 项 → 引商加购 4 项 → 互动 2 项 → 当日转化 4 项 → 7日 4 项 → 15日 4 项：

1. 内容浏览量
2. 内容访客数
3. 人均停留时长
4. 引导进商详访客数
5. 引导进商详浏览量
6. 引导加购人数
7. 引导加购次数
8. 互动人数
9. 互动次数
10. 当日引导成交金额
11. 当日引导成交人数
12. 当日引导成交单量
13. 当日引导商品成交件数
14–17. 7日金额/人数/单量/件数
18–21. 15日金额/人数/单量/件数

### products（16）

1. 引导进商详访客数
2. 引导进商详浏览量
3. 引导加购人数
4. 引导加购次数
5. 当日引导成交金额
6. 当日引导成交人数
7. 当日引导成交单量
8. 当日引导商品成交件数
9–12. 7日金额/人数/单量/件数
13–16. 15日金额/人数/单量/件数

金额为 `null` 表示商智未返回，不应自动补 0。
